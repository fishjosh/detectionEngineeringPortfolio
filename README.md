# detectionEngineeringPortfolio
Detection engineering practice repo
This repo's purpose is to keep a log of my learnings such as writing rule detections, researching the MITRE framework, testing, and working with telemetry  

Started with BOTSv2 for broader SOC-analyst-style investigation practice, and have since 
moved into writing and validating my own Sigma detection rules against real EVTX samples 
(sbousseaden's [EVTX-ATTACK-SAMPLES](https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES)) 
and Atomic Red Team executions in a local VM lab.

| Detection Testing/Validation | Zircolite, Chainsaw, pySigma/sigma-cli |
| Log Sources | Windows Event Logs, Sysmon, Web Proxy, Stream HTTP, OSQuery |

| Languages | PowerBASIC, JavaScript, SQL, Regex |
| Concepts | Threat hunting, indicator-based detection, behavioral detection, rule tuning, false-positive analysis |
